# Assets

This folder is for game sprites and image assets.

## Placeholder assets

Currently the game uses emoji and CSS colours as placeholders for all sprites.
When you are ready to add real artwork, drop PNG/SVG files here and update
the corresponding `TILE_VISUAL` entries in `src/constants.js` and the bear
sprite in `index.html`.

## Recommended asset names

| File | Purpose |
|------|---------|
| bear.png | Happy Bear character sprite |
| tile_locked.png | Locked tile |
| tile_clearable.png | Overgrown tile |
| tile_cleared.png | Cleared soil |
| tile_planted.png | Planted seedling |
| tile_harvestable.png | Ripe fruit tile |
| icon_wood.png | Wood resource icon |
| icon_stone.png | Stone resource icon |
| icon_fruit.png | Fruit resource icon |
| icon_cups.png | Cups resource icon |
